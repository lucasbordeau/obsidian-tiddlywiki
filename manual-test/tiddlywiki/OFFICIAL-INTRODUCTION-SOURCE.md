# Official TiddlyWiki introduction

`official-introduction.json` contains the textual slides from the `introduction`
edition distributed with TiddlyWiki 5.4.1. It deliberately excludes the edition's
images and audio, whose individual metadata does not state a redistribution
license.

- Upstream: <https://github.com/TiddlyWiki/TiddlyWiki5/tree/v5.4.1/editions/introduction>
- Package: `tiddlywiki@5.4.1`
- Copyright: Jeremy Ruston and UnaMesa Association contributors
- License: BSD 3-Clause; see [`TIDDLYWIKI-LICENSE`](./TIDDLYWIKI-LICENSE)
- Generation: `npm run test:manual:fixtures`

The JSON is a redistribution in a different container format. The text and
fields are otherwise left unchanged by the generator.
